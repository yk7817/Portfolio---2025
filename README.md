# Portfolio - 2025
- 2025年にWordPresssで作成したポートフォリオになります。

## 概要
- これまでの実務の実績や、自己紹介・自己スキルを掲載しています。
- jQueryは使用しておらず、Vanilla JSでコーディング、CSS設計はFLOCSS設計

## 主な機能
- レスポンシブ対応
- PIXI、Gsapを使用したアニメーション
- その他動的なDOM操作

## 技術スタック
- WordPress
- HTML / CSS
- SCSS
- JavaScript
- Gsap
- PIXI.js

## 苦労した点
- canvasで作成したオブジェクト(特定の座標に作成した文字列)を1次元配列で「どこに配色が存在するか」を特定する為のロジック、透明度が0ではなく128以上の透明度を特定し、そこにオブジェクトを配置しファーストビューの{ Y.K }を作成しています。ファーストビューの{ Y.K }部分はマウスカーソルでアニメーション(Gsap)ギミックを付けているので試してみてください。
- WordPressのプラグインを使用せず、オリジナルのお問い合わせフォームを設置しています。
